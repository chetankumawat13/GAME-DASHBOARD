# Game Dashboard 🎮

A modern React-based gaming dashboard that displays free-to-play games using API integration.

## ✨ Features

- Browse free-to-play games
- Category filtering
- Game details page
- Save/unsave functionality
- Responsive UI
- React Router navigation
- API-based dynamic data

## ⚙️ Tech Stack

- React
- JavaScript
- CSS
- React Router
- Context API
- FreeToGame API

## 🛣️ Routes

- `/` → Home Page
- `/details/:id` → Game Details
- `/category/:name` → Category Games
- `/saved` → Saved Games

## 📡 API Used

FreeToGame API
